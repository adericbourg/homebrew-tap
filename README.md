# adericbourg/tap

A personal [Homebrew](https://brew.sh) tap by [@adericbourg](https://github.com/adericbourg).

## Usage

### Add and trust this tap

```sh
brew tap adericbourg/tap
brew trust --tap adericbourg/tap
```

The trust step is required from Homebrew ≥ 6.0.0.

### Install a cask

```sh
brew install --cask env-starter
```

Or in a single step, without adding the tap first:

```sh
brew install --cask adericbourg/tap/env-starter
```

Homebrew resolves the tap automatically from the qualified `<user>/<tap>/<token>` name.

## Repository layout

```
homebrew-tap/
├── Casks/     # macOS/Linux cask files (<cask>.rb) — e.g. env-starter, madsister
└── Formula/   # (none yet) Ruby formula files (<formula>.rb)
```

Homebrew auto-discovers `Casks/*.rb` and `Formula/*.rb`.

## Adding or updating an artifact

### Updating an existing cask (env-starter)

`Casks/env-starter.rb` is **auto-generated by [GoReleaser](https://goreleaser.com)** — do not edit it by hand.
To bump the version, cut a new release in the [env-starter](https://github.com/adericbourg/env-starter) repository;
GoReleaser will push an updated cask file to this tap automatically.

### Updating madsister and madsister-snapshot

`Casks/madsister.rb` and `Casks/madsister-snapshot.rb` are **written by the release workflow** of the
[madsister](https://github.com/adericbourg/madsister) repository (the `homebrew` job) — do not edit them by hand.
A release updates `madsister`, every push to its `main` branch updates `madsister-snapshot`. The app isn't signed:
the casks clear the quarantine flag in `postflight`.

### Adding a new cask

1. Create `Casks/<name>.rb` following the [Cask Cookbook](https://docs.brew.sh/Cask-Cookbook).
2. Run `brew install --cask Casks/<name>.rb` to test locally.
3. Run `brew audit --strict Casks/<name>.rb` and fix any warnings.

### Adding a new formula

1. Create `Formula/<name>.rb` following the [Formula Cookbook](https://docs.brew.sh/Formula-Cookbook).
2. Run `brew install --build-from-source Formula/<name>.rb` to test locally.
3. Run `brew audit --strict --new <name>` and fix any warnings.
4. Run `brew test <name>` to verify the installed formula passes its test block.
